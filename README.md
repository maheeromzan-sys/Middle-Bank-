# MIDDLE BANK — Flutter prototype (Android)

*Your Money, Your Security.* / *আপনার অর্থ, আপনার নিরাপত্তা।*

A buyer–seller escrow **assistance prototype**. All 11 screens, Bangla (default) / English switch,
demo data only. **No real payment gateway, no real money.**

## Screens
Splash · Welcome · Login · Create Account · Buyer Dashboard · Seller Dashboard ·
Create Transaction · Secure Payment · Transaction Receipt · Track Transaction · Customer Support

Demo flow: Create Transaction → Secure Payment (simulated) → Receipt → Track.
On Track, the "Demo: move to next step" button walks through shipped → delivered → buyer confirmed → released.
Sellers can mark shipped/delivered from Incoming Transactions.

## Build the APK (needs Flutter SDK + Android SDK on your computer)
This folder contains the Dart source. The native `android/` folder is generated by Flutter:

```bash
cd middle_bank
flutter create --org com.middlebank --project-name middle_bank --platforms android .
flutter pub get
flutter run                       # on a connected phone / emulator
flutter build apk --release       # installable APK -> build/app/outputs/flutter-apk/app-release.apk
```
`flutter create .` keeps the existing `lib/` and `pubspec.yaml`. If it overwrites `lib/main.dart`, restore it from this project.

Keep Flutter's default `minSdk` (it covers all mainstream Android versions still in use).
Bangla text uses the phone's built-in Noto Sans Bengali; to guarantee identical rendering on every
brand, bundle the font under `assets/fonts/` and declare it in `pubspec.yaml`.

## Before a Play Store release
1. Set a real `applicationId` and app name/icon (e.g. `flutter_launcher_icons`).
2. Create an upload keystore, add `android/key.properties`, wire signing in `android/app/build.gradle`.
3. `flutter build appbundle --release` and upload the `.aab`.
4. Check the current Play Console target-API requirement and Financial Services declaration.
5. **Do not publish this as a live payment service.** Holding or moving customers' money needs a licensed
   payment partner, backend, KYC, security review and legal approval. This prototype has none of that.

## Test matrix (no guarantee it works on every device — test these)
- Android versions: oldest your minSdk allows, 10, 12, 13, 14, latest.
- Brands: Samsung, Xiaomi/Redmi, Vivo, Oppo, Realme, Pixel, OnePlus, Motorola, Tecno, Infinix.
- Screens: small (~320 dp wide), normal (~360–411 dp), large; also system font size = Large, and display size = Large.
- Check per screen: no overflow, buttons reachable with keyboard open, Bangla ↔ English switch, back navigation.
- Low-end: run `flutter run --profile` on a 2–3 GB RAM phone and watch for jank on the splash animation.
